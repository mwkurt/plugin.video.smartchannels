# plugin.video.smartchannels
# Smart TV Channels for Kodi

A Kodi 21 Omega addon that transforms your local video library into smart virtual TV channels — just like real TV, but with your own content.

## Features

- **TV Channels** — Round-robin episode interleaving across multiple shows. Random or sequential rotation.
- **Serial Mode** — Play all episodes of Show A, then Show B, then Show C. Optional shuffle of show order each cycle.
- **Movie Channels** — Continuous movie playback with random or sequential rotation.
- **Exact Resume** — Stop mid-episode and pick up exactly where you left off, including after a Kodi crash.
- **Interleave** — Insert movie or TV content between episodes at configurable intervals.
- **Multi-client Support** — Shared SMB storage lets multiple Kodi instances share the same channel state.
- **Backup & Restore** — Export and import all channel data to a zip file.
- **Queue Management** — Persistent queues with automatic top-up, configurable size, and no-repeat tracking.

## Requirements

- Kodi 21 Omega or later
- Python 3
- Local video library configured in Kodi

## Installation

1. Download the latest zip from the Releases page
2. In Kodi: Add-ons → Install from zip file
3. Select the downloaded zip
